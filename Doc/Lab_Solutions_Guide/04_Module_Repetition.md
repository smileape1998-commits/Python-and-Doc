## 04-01: Multiples of 3 or 5

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
รับจำนวนเต็มบวก $n$ แล้วคำนวณผลรวมของจำนวนเต็มบวกทั้งหมดที่ **น้อยกว่า $n$** ซึ่งเป็นพหุคูณของ 3 หรือ 5 (หารด้วย 3 หรือ 5 ลงตัว)

- **ตัวอย่าง:** ถ้า $n = 10$ จำนวนที่เข้าเกณฑ์คือ $3, 5, 6, 9$ $ightarrow$ ผลรวมเท่ากับ $3+5+6+9 = 23$

---

### 💻 2. โค้ดเฉลยฉบับสมบูรณ์
```python
n = int(input())
total = 0
for i in range(1, n):
    if i % 3 == 0 or i % 5 == 0:
        total += i
print(total)
```

---

### 🔍 3. อธิบายการทำงาน
- `range(1, n)`: วนตั้งแต่ $1$ จนถึง $n-1$ (ตรงตามเงื่อนไข "น้อยกว่า $n$")
- `if i % 3 == 0 or i % 5 == 0:`: ตรวจสอบว่าหาร 3 ลงตัว หรือหาร 5 ลงตัว (ถ้าหารลงตัวทั้งสองตัว เช่น 15 ก็จะเข้าเงื่อนไขเพียงรอบเดียว ไม่บวกเบิ้ล)
- `total += i`: บวกสะสมค่า $i$ เข้ากับตัวแปรผลรวม

## 04-03: ค่าเฉลี่ย

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
รับตัวเลขจำนวนจริงจากผู้ใช้ทีละบรรทัดไปเรื่อยๆ จนกว่าจะพิมพ์ตัวอักษร `'q'` เพื่อหยุดรับข้อมูล แล้วแสดงค่าเฉลี่ยของตัวเลขทั้งหมด ปัดเศษทศนิยม 2 ตำแหน่ง (ถ้าไม่ป้อนตัวเลขใดๆ เลย ให้พิมพ์ `No Data`)

---

### 💡 2. ทำไมถึงเขียนแบบนี้? (รูปแบบ Sentinel Loop)
เมื่อเราไม่รู้ล่วงหน้าว่าผู้ใช้จะพิมพ์ข้อมูลมากี่ตัว เราจะใช้ `while True:` เพื่อวนรับค่าไม่รู้จบ และดักเงื่อนไขหยุด (Exit Condition) ด้วยคำสั่ง `break` เมื่อเจอตัวสิ้นสุด (Sentinel Value) คือ `'q'`

---

### 💻 3. โค้ดเฉลยฉบับสมบูรณ์
```python
total = 0.0
count = 0

while True:
    line = input()
    if line == "q":
        break
    total += float(line)
    count += 1

if count > 0:
    print(round(total / count, 2))
else:
    print("No Data")
```

---

### 🎙️ 4. สคริปต์คำพูดสำหรับใช้สอน / Live Code
> **ผู้สอน:** *"กับดักอันดับ 1 ของโจทย์ข้อนี้คือ **ZeroDivisionError** ครับ!*
> *ถ้าผู้ใช้เปิดโปรแกรมมาแล้วกด 'q' ทันที `count` จะเป็น 0 ถ้าเราสั่ง `total / count` ตรงๆ โปรแกรมจะแครชทันที!*
> *ดังนั้นเราต้องมี `if count > 0:` เพื่อป้องกันการหารด้วยศูนย์เสมอครับ"*

## 04-04: การประมาณค่าของ log10 a ด้วย bisection

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
รับค่าจำนวนจริง $a > 0$ แล้วประมาณค่าของ $x = \log_{10}(a)$ ซึ่งหมายถึงการแก้สมการ $10^x = a$ โดยใช้วิธี **การแบ่งครึ่งช่วง (Bisection Method)** จนกว่าค่าความผิดพลาดสัมพัทธ์จะน้อยกว่า $10^{-10} \times \max(a, 10^x)$

---

### 💡 2. ทำไมถึงเขียนแบบนี้? (หลักการ Bisection Search)
1. กำหนดช่วงเริ่มต้น: ขอบล่าง $L = 0.0$, ขอบบน $U = a$
2. หาจุดกึ่งกลาง: $x = \frac{L + U}{2.0}$
3. ตรวจสอบ $10^x$:
   - ถ้า $10^x > a$ แสดงว่าค่า $x$ ที่เดาไว้มากเกินไป $ightarrow$ หดขอบบนลงมา $U = x$
   - ถ้า $10^x \le a$ แสดงว่าค่า $x$ ที่เดาไว้น้อยเกินไป $ightarrow$ ขยับขอบล่างขึ้นไป $L = x$
4. ทำซ้ำจนกว่าความต่าง $|a - 10^x|$ จะน้อยกว่าเกณฑ์ที่กำหนด

---

### 💻 3. โค้ดเฉลยฉบับสมบูรณ์
```python
a = float(input())

L = 0.0
U = a
x = (L + U) / 2.0

while abs(a - 10**x) > 10**(-10) * max(a, 10**x):
    if 10**x > a:
        U = x
    else:
        L = x
    x = (L + U) / 2.0

print(round(x, 6))
```

## 04-07: การนับจำนวนคำที่สนใจ

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
รับคำค้นหา (`target`) และข้อความยาว (`text`) ให้นับว่ามีคำว่า `target` ปรากฏกี่ครั้ง โดยไม่นับรวมเครื่องหมายวรรคตอน เช่น `" ( ) , . '`

---

### 💡 2. ทำไมถึงเขียนแบบนี้? (Sanitization + Tokenization)
1. **Punctuation Stripping:** วนลูปตรวจอักขระทุกตัวในข้อความ หากเป็นเครื่องหมายวรรคตอน ให้แปลงเป็นช่องว่าง `' '`
2. **Tokenization:** ใช้ `.split()` เพื่อตัดข้อความสะอาดให้กลายเป็น List ของคำ
3. **Exact Matching:** วนลูปนับคำที่ตรงกับ `target`

---

### 💻 3. โค้ดเฉลยฉบับสมบูรณ์
```python
target = input()
text = input()

# แทนที่เครื่องหมายวรรคตอนด้วยช่องว่าง
punct = ""(),.'"
clean_text = ""
for c in text:
    if c in punct:
        clean_text += " "
    else:
        clean_text += c

# แยกคำและนับจำนวน
words = clean_text.split()
count = 0
for w in words:
    if w == target:
        count += 1

print(count)
```

## 04-08: การวาดสามเหลี่ยมสูง h

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
รับความสูง $h$ แล้ววาดภาพสามเหลี่ยมกลวง (Hollow Triangle) ที่มีความสูง $h$ บรรทัดด้วยเครื่องหมาย `*`

- **ตัวอย่างเมื่อ $h=4$:**
```text
   *
  * *
 *   *
*******
```

---

### 💡 2. ทำไมถึงเขียนแบบนี้? (วิเคราะห์ Pattern ของแต่ละบรรทัด)
สังเกตว่าแต่ละบรรทัด $i$ (ตั้งแต่ $1$ ถึง $h$) มีรูปแบบที่แตกต่างกัน 3 กรณี:
1. **บรรทัดยอด ($i = 1$):** เว้นวรรคข้างหน้า $h-1$ ช่อง แล้วพิมพ์ `*` ตัวเดียว
2. **บรรทัดฐาน ($i = h$):** พิมพ์ `*` ตันตลอดแถวเป็นจำนวน $2h - 1$ ตัว
3. **บรรทัดกลาง ($1 < i < h$):**
   - เว้นวรรคข้างหน้า: $h - i$ ช่อง
   - ดอกจันซ้าย: `*`
   - เว้นวรรคข้างใน: $2i - 3$ ช่อง (เช่น บรรทัด 2 เว้น 1 ช่อง, บรรทัด 3 เว้น 3 ช่อง, บรรทัด 4 เว้น 5 ช่อง)
   - ดอกจันขวา: `*`

---

### 💻 3. โค้ดเฉลยฉบับสมบูรณ์
```python
h = int(input())

for i in range(1, h + 1):
    if i == 1:
        print(" " * (h - 1) + "*")
    elif i == h:
        print("*" * (2 * h - 1))
    else:
        spaces_before = " " * (h - i)
        spaces_inside = " " * (2 * i - 3)
        print(spaces_before + "*" + spaces_inside + "*")
```
