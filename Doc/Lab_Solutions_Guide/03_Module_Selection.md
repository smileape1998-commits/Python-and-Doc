## 03-01: มัธยฐานของจำนวน 3 จำนวน

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
รับจำนวนเต็ม 3 จำนวน $a, b, c$ ในบรรทัดเดียว แล้วหาค่า **มัธยฐาน (Median)** ซึ่งก็คือค่าที่อยู่ตรงกลางเมื่อนำทั้งสามจำนวนมาเรียงลำดับ

- **Input:** `30 10 20`
- **Output:** `20`

---

### 💡 2. ทำไมถึงเขียนแบบนี้? (Chained Comparison ใน Python)
ในภาษา Python มีคุณสมบัติพิเศษที่ภาษาอื่นไม่มีคือ **Chained Comparison** เช่น `b <= a <= c` (หมายถึง $b \le a$ และ $a \le c$)
ดังนั้นเงื่อนไขที่ $a$ จะเป็นค่าตรงกลางมีเพียง 2 กรณี:
1. $b \le a \le c$ (เมื่อ $b$ น้อยสุด, $c$ มากสุด)
2. $c \le a \le b$ (เมื่อ $c$ น้อยสุด, $b$ มากสุด)

ถ้าไม่ใช่ทั้งสองกรณี ก็ไปตรวจ $b$ ในทำนองเดียวกัน ถ้าไม่ใช่ทั้ง $a$ และ $b$ ตัวที่เหลือคือ $c$ ย่อมเป็นคำตอบแน่นอน!

---

### 💻 3. โค้ดเฉลยฉบับสมบูรณ์
```python
# 03-01: มัธยฐานของจำนวน 3 จำนวน
a, b, c = [int(x) for x in input().split()]

if (b <= a <= c) or (c <= a <= b):
    med = a
elif (a <= b <= c) or (c <= b <= a):
    med = b
else:
    med = c

print(med)
```

## 03-02: ตรวจสอบวงกลมทับกันหรือแตะกัน

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
รับข้อมูลวงกลม 2 วง โดยแต่ละวงระบุพิกัดศูนย์กลางและรัศมี $(x_1, y_1, r_1)$ และ $(x_2, y_2, r_2)$
ให้ตรวจสอบความสัมพันธ์ระหว่างวงกลมทั้งสอง:
- `touch`: ขอบวงกลมแตะกันพอดี
- `overlap`: วงกลมซ้อนทับกัน (กินพื้นที่กัน)
- `free`: วงกลมแยกจากกัน ไม่สัมผัสกัน

---

### 💡 2. ทำไมถึงเขียนแบบนี้? (คณิตศาสตร์ & Floating-Point Epsilon)
1. **ระยะห่างระหว่างจุดศูนย์กลาง ($d$):**
   $$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$
2. **ผลรวมของรัศมี ($r_{\text{sum}}$):** $r_{\text{sum}} = r_1 + r_2$
3. **กับดักเรื่อง Float:** การเปรียบเทียบ `d == r_sum` ในคอมพิวเตอร์อาจเกิดความคลาดเคลื่อนจากเลขทศนิยมไม่รู้จบ (เช่น $0.1 + 0.2 = 0.30000000000000004$)
   ดังนั้น การตรวจสอบว่า "แตะกันพอดีหรือไม่" ต้องใช้ **Epsilon Tolerance**:
   `abs(d - r_sum) < 1e-9` (ผลต่างน้อยกว่า $10^{-9}$)

---

### 💻 3. โค้ดเฉลยฉบับสมบูรณ์
```python
import math

# รับพิกัดและรัศมีของวงกลมทั้งสอง
x1, y1, r1 = [float(x) for x in input().split()]
x2, y2, r2 = [float(x) for x in input().split()]

# คำนวณระยะห่างระหว่างจุดศูนย์กลาง
d = math.sqrt((x2 - x1)**2 + (y2 - y1)**2)
r_sum = r1 + r2

# ตรวจสอบเงื่อนไขตามลำดับ
if abs(d - r_sum) < 1e-9:
    print("touch")
elif d < r_sum:
    print("overlap")
else:
    print("free")
```

## 03-03: Days in Month

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
รับข้อมูลเดือน ($m$) และปี พ.ศ. ($y_{\text{buddhist}}$) แล้วแสดงจำนวนวันในเดือนนั้น โดยต้องคำนวณปีกุมภาพันธ์ที่มี 29 วัน (ปีอธิกสุรทิน / Leap Year) ตามปฏิทินสากล ค.ศ.

---

### 💡 2. ทำไมถึงเขียนแบบนี้?
1. **แปลง พ.ศ. เป็น ค.ศ.:** $y = y_{\text{buddhist}} - 543$ เพราะกฎสากลของ Leap Year คิดบน ค.ศ.
2. **กฎ Leap Year ของปฏิทินเกรกอเรียน:**
   - ปีที่หารด้วย 400 ลงตัว $ightarrow$ เป็น Leap Year (`y % 400 == 0`)
   - ปีที่หารด้วย 4 ลงตัว **แต่** หารด้วย 100 ไม่ลงตัว $ightarrow$ เป็น Leap Year (`y % 4 == 0 and y % 100 != 0`)
3. **การจัดกลุ่มเดือน:**
   - เดือนที่มี 31 วัน: `m in [1, 3, 5, 7, 8, 10, 12]`
   - เดือนที่มี 30 วัน: `m in [4, 6, 9, 11]`

---

### 💻 3. โค้ดเฉลยฉบับสมบูรณ์
```python
m, y_buddhist = [int(x) for x in input().split()]
y = y_buddhist - 543

if m in [1, 3, 5, 7, 8, 10, 12]:
    days = 31
elif m in [4, 6, 9, 11]:
    days = 30
elif m == 2:
    if (y % 400 == 0) or (y % 4 == 0 and y % 100 != 0):
        days = 29
    else:
        days = 28

print(days)
```

## 03-04: คิดค่าที่จอดรถ

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
รับเวลาเข้า ($h_1, m_1$) และเวลาออก ($h_2, m_2$) ภายในวันเดียวกัน คำนวณค่าจอดรถตามอัตราก้าวหน้า:
- ไม่เกิน 15 นาที: **ฟรี** (0 บาท)
- เกิน 15 นาที แต่ไม่เกิน 3 ชั่วโมง: ชั่วโมงละ 10 บาท (เศษของชั่วโมงคิดเป็น 1 ชั่วโมงเต็ม)
- 4 ถึง 6 ชั่วโมง: ชั่วโมงที่ 1-3 คิด 30 บาท + ชั่วโมงที่เกินคิดชั่วโมงละ 20 บาท
- เกิน 6 ชั่วโมงขึ้นไป: เหมาจ่าย **200 บาท**

---

### 💡 2. ทำไมถึงเขียนแบบนี้? (เทคนิคปัดเศษชั่วโมงขึ้นด้วย Integer Division)
1. หาผลต่างเวลารวมเป็นนาที: `diff = (h2*60 + m2) - (h1*60 + m1)`
2. การปัดเศษนาทีขึ้นเป็น 1 ชั่วโมง (Ceil Division):
   - หากเวลาเป็น 1 นาที จะคิดเป็น 1 ชม.
   - หากเวลาเป็น 60 นาที คิด 1 ชม.
   - หากเวลาเป็น 61 นาที คิด 2 ชม.
   - *สูตรคณิตศาสตร์คอมพิวเตอร์:* `(diff + 59) // 60` ให้ผลลัพธ์เท่ากับ `math.ceil(diff / 60)` เสมอโดยไม่ต้องพึ่ง Float!

---

### 💻 3. โค้ดเฉลยฉบับสมบูรณ์
```python
h1 = int(input())
m1 = int(input())
h2 = int(input())
m2 = int(input())

t1 = h1 * 60 + m1
t2 = h2 * 60 + m2
diff = t2 - t1

if diff <= 15:
    fee = 0
elif diff <= 180:  # 3 ชั่วโมง = 180 นาที
    hours = (diff + 59) // 60
    fee = hours * 10
elif diff <= 360:  # 6 ชั่วโมง = 360 นาที
    hours = (diff + 59) // 60
    fee = 30 + (hours - 3) * 20
else:
    fee = 200

print(fee)
```

## 03-11: การแสดงตัวเลขแบบย่อ

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
รับจำนวนเต็ม $n$ แล้วจัดรูปแบบแสดงตัวเลขย่อ (เช่น ยอดวิว, ยอดติดตาม):
- $n < 1,000$: แสดงตัวเลขเดิม
- $1,000 \le n < 10,000$: หาร 1,000 ปัดเศษ 1 ตำแหน่งตามด้วย `K` (ถ้าลงตัวให้เป็นจำนวนเต็ม เช่น `1K`, `1.5K`)
- $10,000 \le n < 1,000,000$: ตัดเศษทิ้งแสดงเป็นจำนวนเต็ม `K` (เช่น `25K`, `999K`)
- $n \ge 1,000,000$: หาร 1,000,000 ปัดเศษ 1 ตำแหน่งตามด้วย `M` (ถ้าลงตัวให้เป็นจำนวนเต็ม เช่น `2M`, `3.4M`)

---

### 💻 2. โค้ดเฉลยฉบับสมบูรณ์
```python
n = int(input())

if n < 1000:
    print(n)
elif n < 10000:
    val = round(n / 1000, 1)
    if val == int(val):
        print(f"{int(val)}K")
    else:
        print(f"{val}K")
elif n < 1000000:
    print(f"{n // 1000}K")
else:
    val = round(n / 1000000, 1)
    if val == int(val):
        print(f"{int(val)}M")
    else:
        print(f"{val}M")
```
