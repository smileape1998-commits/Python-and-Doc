## 06-01: การปรับส่วนของโปรแกรมให้เป็นฟังก์ชัน

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
โจทย์ต้องการให้เขียนฟังก์ชัน 3 ฟังก์ชันสำหรับคำนวณหา **พื้นที่ผิวร่างกาย (Body Surface Area: BSA)** จากน้ำหนัก $w$ (กก.) และส่วนสูง $h$ (ซม.) ตามสูตรทางการแพทย์ 3 สูตร:
1. **Mosteller:** $\text{BSA} = \frac{\sqrt{w \times h}}{60}$
2. **Du Bois:** $\text{BSA} = 0.007184 \times w^{0.425} \times h^{0.725}$
3. **Fujimoto:** $\text{BSA} = 0.008883 \times w^{0.444} \times h^{0.663}$

และสร้างฟังก์ชัน `main()` เพื่อรับ $w, h$ แล้วพิมพ์ผลลัพธ์ทั้ง 3 สูตรปัดเศษทศนิยม 5 ตำแหน่ง

---

### 💡 2. ทำไมถึงเขียนแบบนี้? (หลักการ Modular Design & Pure Functions)
- แต่ละฟังก์ชันทำหน้าที่เพียงอย่างเดียว (Single Responsibility Principle)
- ฟังก์ชันคำนวณจะรับค่า $w, h$ แล้ว `return` ตัวเลขผลลัพธ์กลับมา โดยไม่ยุ่งเกี่ยวกับ `print()` หรือ `input()`
- ฟังก์ชัน `main()` ทำหน้าที่ควบคุม Flow การรับข้อมูล แปลงชนิดข้อมูล เรียกใช้ฟังก์ชันย่อย และจัดรูปแบบการแสดงผล

---

### 💻 3. โค้ดเฉลยฉบับสมบูรณ์
```python
# 06-01: การปรับส่วนของโปรแกรมให้เป็นฟังก์ชัน
import math

def mosteller(w, h):
    """คำนวณ BSA ตามสูตร Mosteller"""
    return (w * h) ** 0.5 / 60

def du_bois(w, h):
    """คำนวณ BSA ตามสูตร Du Bois"""
    return 0.007184 * (w ** 0.425) * (h ** 0.725)

def fujimoto(w, h):
    """คำนวณ BSA ตามสูตร Fujimoto"""
    return 0.008883 * (w ** 0.444) * (h ** 0.663)

def main():
    weight = float(input())
    height = float(input())
    
    mos = mosteller(weight, height)
    dub = du_bois(weight, height)
    fuj = fujimoto(weight, height)
    
    print("Mosteller =", round(mos, 5))
    print("Du Bois =", round(dub, 5))
    print("Fujimoto =", round(fuj, 5))

exec(input())  # DON'T remove this line (สำหรับการตรวจระบบ Grader)
```

### 🎙️ 4. สคริปต์คำพูดสำหรับใช้สอน / Live Code
> **ผู้สอน:** *"สังเกตว่าทำไมในฟังก์ชัน `mosteller`, `du_bois`, `fujimoto` เราถึงใช้ `return` แทนที่จะ `print()` ทันที?*
> *เพราะการเขียนฟังก์ชันที่ดีต้องมีความยืดหยุ่น (Reusability) หากระบบอื่นอยากนำค่า BSA ไปคำนวณขนาดยาต่อ ถ้าเรา `print()` ทิ้งไว้ ค่าจะหายไปในอากาศและนำไปคิดเลขต่อไม่ได้ การ `return` ค่าออกมาทำให้ฟังก์ชันสามารถนำไปต่อยอดได้ไม่จำกัดครับ"*

## 06-04: การบวกเลขฐานสอง

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
รับสตริงเลขฐานสอง 2 จำนวนที่คั่นด้วยช่องว่าง เช่น `"1010 11"` แล้วคำนวณผลบวกของเลขฐานสองทั้งสอง และแสดงผลลัพธ์กลับมาเป็นสตริงเลขฐานสอง (เช่น `"1101"`)

---

### 💡 2. ทำไมถึงเขียนแบบนี้? (Built-in Base Conversion vs การทดเลขด้วยตนเอง)
ใน Python มีฟังก์ชันแปลงฐานตัวเลขที่ทรงพลังมาก:
1. `int(str_binary, 2)`: พารามิเตอร์ตัวที่สองระบุฐาน (Base 2) ช่วยแปลงสตริงเลขฐานสองเป็นจำนวนเต็มฐานสิบได้ทันที
2. บวกกันตามปกติ: `num1 + num2`
3. `bin(sum_val)`: แปลงจำนวนเต็มกลับเป็นสตริงฐานสอง ซึ่งจะได้ข้อความขึ้นต้นด้วย `"0b"` เสมอ เช่น `"0b1101"`
4. ตัด `"0b"` ออกด้วย String Slicing: `[2:]`

---

### 💻 3. โค้ดเฉลยฉบับสมบูรณ์
```python
# 06-04: การบวกเลขฐานสอง

# 1. รับสตริงเลขฐานสอง 2 ชุด คั่นด้วยช่องว่าง
binary1_str, binary2_str = input().split()

# 2. แปลงจากสตริงเลขฐานสองเป็นจำนวนเต็มฐานสิบ
num1 = int(binary1_str, 2)
num2 = int(binary2_str, 2)

# 3. คำนวณผลบวก
sum_val = num1 + num2

# 4. แปลงผลบวกเป็นสตริงเลขฐานสอง และตัดสัญลักษณ์ "0b" ออกด้านหน้า
result_binary = bin(sum_val)[2:]

# 5. แสดงผลลัพธ์
print(result_binary)
```
