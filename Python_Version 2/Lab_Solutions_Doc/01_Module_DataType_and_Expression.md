## 01-01: สูตรแปลก ๆ

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
โจทย์ต้องการให้คำนวณค่าจากนิพจน์ทางคณิตศาสตร์ที่ซับซ้อน:

$$\frac{\pi - \frac{10!}{8^{5}} + (\log_{e} 9.7)\sqrt[7]{71} - \sin(40^{\circ})}{(1.2)\sqrt[3]{2.3}}$$

- **Input:** ไม่มี
- **Output:** ค่าตัวเลขทศนิยมปัดเศษไม่เกิน 6 ตำแหน่ง (ใช้ `round(..., 6)`)

---

### 💡 2. ทำไมถึงเขียนแบบนี้? (แนวคิด & การออกแบบ)
1. **แยกตัวเศษ (Numerator) และตัวส่วน (Denominator):** แทนที่จะเขียนเป็นสมการบรรทัดเดียวยาวเหยียดซึ่งอ่านยากและเสี่ยงต่อการใส่วงเล็บผิด เราแยกเป็น 2 ตัวแปรเพื่อให้อ่านง่ายและตรวจสอบความถูกต้องได้ทีละท่อน
2. **การเลือกใช้ฟังก์ชันจาก `math`:**
   - ค่า $\pi$ ใช้ `math.pi` (ไม่ใช่ 3.14 หรือ 22/7 เพราะต้องการความแม่นยำสูง)
   - แฟกทอเรียล $10!$ ใช้ `math.factorial(10)`
   - ลอการิทึมธรรมชาติ $\log_e(9.7)$ ใช้ `math.log(9.7)` (ใน Python ฟังก์ชัน `math.log(x)` คือฐาน $e$ เป็นค่าตั้งต้น)
   - ฟังก์ชันตรีโกณมิติ $\sin(40^\circ)$ ในคอมพิวเตอร์รับมุมเป็น **เรเดียน (Radians)** เสมอ จึงต้องแปลงด้วย `math.radians(40)`
   - การหารากที่ $n$ ($\\sqrt[n]{x}$) ใน Python ไม่มีฟังก์ชันรากที่ $n$ โดยตรง จึงใช้คณิตศาสตร์แปลงเป็นเลขยกกำลังเศษส่วน $x^{\frac{1}{n}}$ เช่น `71 ** (1 / 7)`

---

### 💻 3. โค้ดเฉลยฉบับสมบูรณ์
```python
import math

# คำนวณส่วนของตัวเศษ
numerator = (
    math.pi
    - (math.factorial(10) / (8 ** 5))
    + (math.log(9.7) * (71 ** (1 / 7)))
    - math.sin(math.radians(40))
)

# คำนวณส่วนของตัวส่วน
denominator = 1.2 * (2.3 ** (1 / 3))

# หาผลหารรวมและปัดเศษทศนิยม 6 ตำแหน่ง
ans = numerator / denominator
print(round(ans, 6))
```

---

### 🔍 4. อธิบายการทำงานทีละบรรทัด
- `import math`: โหลดโมดูลคณิตศาสตร์มาตรฐานของ Python เพื่อนำฟังก์ชัน `pi`, `factorial`, `log`, `sin`, `radians` มาใช้
- `math.factorial(10) / (8 ** 5)`: คำนวณ $10! = 3,628,800$ แล้วหารด้วย $8^5 = 32,768$
- `(math.log(9.7) * (71 ** (1 / 7)))`: คำนวณ $\ln(9.7) \approx 2.2721$ คูณด้วย $71^{1/7} \approx 1.8368$
  - *จุดสำคัญ:* ต้องใส่วงเล็บรอบ `(1 / 7)` เสมอ เพราะถ้าเขียน `71 ** 1 / 7` ไพธอนจะคิด `(71 ** 1) / 7` ตามลำดับความสำคัญของตัวดำเนินการ
- `math.sin(math.radians(40))`: แปลง 40 องศาเป็นเรเดียนก่อนส่งให้ `sin()`
- `denominator = 1.2 * (2.3 ** (1 / 3))`: คำนวณตัวส่วน $1.2 \times \sqrt[3]{2.3}$
- `round(ans, 6)`: ปัดเศษผลลัพธ์เป็นทศนิยม 6 ตำแหน่งตามที่โจทย์ระบุ

### 🎙️ 5. สคริปต์คำพูดสำหรับใช้สอน / Live Code

> 1. *รากที่ 7 ของ 71 เขียนยังไง? ในคอมพิวเตอร์คือ `71 ** (1/7)` อย่าลืมวงเล็บที่ `(1/7)` เด็ดขาด ไม่งั้นจะกลายเป็น $71^1 \div 7$ ทันที*

> 3. *ถ้าสูตรยาวแบบนี้ อย่าเขียนบรรทัดเดียวรวดเดียวจนล้นจอ ให้แยก `numerator` กับ `denominator` จะทำให้โค้ดเราอ่านง่ายและไม่หลงวงเล็บครับ"*

## 01-02: การประมาณค่าของ n !

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
โจทย์ต้องการคำนวณหา **ขอบเขตล่าง (Lower Bound)** และ **ขอบเขตบน (Upper Bound)** ของการประมาณค่า $n!$ ตามสูตร Stirling's Approximation:

$$\sqrt{2\pi} n^{n+\frac{1}{2}} e^{-n+\frac{1}{12n+1}} < n! < \sqrt{2\pi} n^{n+\frac{1}{2}} e^{-n+\frac{1}{12n}}$$

- **Input:** จำนวนเต็ม $n$ (เช่น 1, 5, 50, 100)
- **Output:** แสดงค่า Lower bound และ Upper bound บรรทัดละค่า

---

### 💡 2. ทำไมถึงเขียนแบบนี้?
1. **การรับค่า Input:** ตัวแปร $n$ เป็นจำนวนเต็ม ต้องแปลงด้วย `int(input())`
2. **ตัวคูณร่วม (Common Factor):** ทั้งสองสูตรมีพจน์นำหน้าเหมือนกันคือ $\sqrt{2\pi} \cdot n^{n+0.5}$
3. **การคำนวณ $e^x$:** ใช้ `math.exp(x)` แทน `math.e ** x` เนื่องจาก `math.exp()` ให้ความแม่นยำเชิงตัวเลข (numerical precision) ที่สูงกว่าและเร็วกว่า
4. **ความแม่นยำของวงเล็บ:** สูตรขอบล่างมีส่วนเป็น $12n+1$ ต้องเขียนเป็น `1 / (12 * n + 1)` เพื่อไม่ให้ลำดับตัวดำเนินการผิด

---

### 💻 3. โค้ดเฉลยฉบับสมบูรณ์
```python
import math

n = int(input())

# ขอบเขตล่าง (Lower bound)
lower_bound = (
    math.sqrt(2 * math.pi)
    * (n ** (n + 0.5))
    * math.exp(-n + 1 / (12 * n + 1))
)

# ขอบเขตบน (Upper bound)
upper_bound = (
    math.sqrt(2 * math.pi)
    * (n ** (n + 0.5))
    * math.exp(-n + 1 / (12 * n))
)

print(lower_bound)
print(upper_bound)
```

---

### 🔍 4. อธิบายการทำงานทีละบรรทัด
- `n = int(input())`: รับข้อความจากคีย์บอร์ดและแปลงเป็นจำนวนเต็ม
- `math.sqrt(2 * math.pi)`: คำนวณ $\sqrt{2\pi}$
- `(n ** (n + 0.5))`: คำนวณ $n^{n+0.5}$ (ใช้ `0.5` แทน `1/2` เพื่อลดรูปวงเล็บ)
- `math.exp(-n + 1 / (12 * n + 1))`: คำนวณ $e^{-n + \frac{1}{12n+1}}$
- `print(lower_bound)` และ `print(upper_bound)`: พิมพ์ค่าทั้งสองตามลำดับ

---

### 🎙️ 5. สคริปต์คำพูดสำหรับใช้สอน / Live Code
> **ผู้สอน:** *"สังเกตไหมครับว่าสูตรสองบรรทัดนี้ต่างกันแค่นิดเดียว ตรงส่วนของเลขชี้กำลัง $e$:*
> *ฝั่งขอบล่างคือ `1 / (12 * n + 1)` ส่วนขอบบนคือ `1 / (12 * n)`*
> *จุดที่ต้องเตือนตัวเองคือ อย่าลืมเครื่องหมายคูณ `*` ระหว่าง `12` กับ `n` ในคณิตศาสตร์เขียนติดกันได้ $12n$ แต่ในภาษาโปรแกรมมิ่งต้องเขียน `12 * n` เสมอครับ"*

## 01-03: ช่วงเวลา

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
รับเวลาเริ่มต้น $h_1, m_1, s_1$ และเวลาสิ้นสุด $h_2, m_2, s_2$ (บรรทัดละจำนวน) แล้วคำนวณหาระยะเวลาที่ผ่านไปในรูปแบบ `dh:dm:ds` โดยต้องรองรับกรณีที่เวลาสิ้นสุดข้ามไปอีกวันหนึ่งด้วย (เช่น เริ่ม 23:00 จบ 01:00)

- **Input:** $h_1, m_1, s_1, h_2, m_2, s_2$ บรรทัดละค่า
- **Output:** ช่วงเวลา `ชั่วโมง:นาที:วินาที` (เช่น `1:49:40`)

---

### 💡 2. ทำไมถึงเขียนแบบนี้? (หัวใจสำคัญ: การแปลงหน่วยเป็นฐานเดี่ยว)
1. **แปลงทุกอย่างเป็น "วินาที" (Base Unit):**
   การคิดเลขเวลาที่มีหน่วยผสม (ชั่วโมง, นาที, วินาที) โดยตรงจะเกิดความยุ่งยากมากตอนมีการยืมข้ามหลัก (Borrowing) ดังนั้นวิธีที่เป็นมาตรฐานที่สุดคือ:
   - แปลงเวลาเริ่มต้นเป็นวินาทีทั้งหมด: $t_1 = h_1 \times 3600 + m_1 \times 60 + s_1$
   - แปลงเวลาสิ้นสุดเป็นวินาทีทั้งหมด: $t_2 = h_2 \times 3600 + m_2 \times 60 + s_2$
2. **การจัดการกรณีข้ามวันด้วย Modulo (`%`):**
   - 1 วันมี $24 \times 3600 = 86,400$ วินาที
   - ผลต่างเวลา $dt = (t_2 - t_1) \pmod{86400}$
   - ข้อดีของ `% 86400` ใน Python คือ: **ถ้า $t_2 < t_1$ (เช่น เริ่ม 23:00 จบ 01:00 ทำให้ $t_2 - t_1$ เป็นลบ) ไพธอนจะจัดการ Wrap-around ให้กลายเป็นค่าบวกในรอบ 24 ชั่วโมงให้อัตโนมัติทันที!** (เช่น $-1 \pmod{24} = 23$)
3. **แปลงวินาทีกลับเป็น `h:m:s` ด้วย Integer Division (`//`) และ Modulo (`%`):**
   - ชั่วโมง $dh = dt // 3600$
   - วินาทีที่เหลือ $dt = dt \% 3600$
   - นาที $dm = dt // 60$
   - วินาทีสุดท้าย $ds = dt \% 60$

---

### 💻 3. โค้ดเฉลยฉบับสมบูรณ์
```python
# รับข้อมูลเวลาเริ่มต้น
h1 = int(input())
m1 = int(input())
s1 = int(input())

# รับข้อมูลเวลาสิ้นสุด
h2 = int(input())
m2 = int(input())
s2 = int(input())

# แปลงเวลาทั้งสองจุดเป็นวินาทีทั้งหมด
t1 = h1 * 3600 + m1 * 60 + s1
t2 = h2 * 3600 + m2 * 60 + s2

# คำนวณช่วงเวลา โดยใช้ Modulo เพื่อรองรับกรณีข้ามเที่ยงคืน (ข้ามวัน)
dt = (t2 - t1) % (24 * 3600)

# แปลงวินาทีกลับเป็น ชั่วโมง : นาที : วินาที
dh = dt // 3600
dt %= 3600
dm = dt // 60
ds = dt % 60

# แสดงผลในรูปแบบ dh:dm:ds
print(f"{dh}:{dm}:{ds}")
```

---

### 🧪 4. ตาราง Trace ค่าตัวแปร (ตัวอย่างการทำงาน)
สมมติเวลาเริ่มต้นคือ `23:50:00` และเวลาสิ้นสุดคือ `00:10:00` (ข้ามวัน 20 นาที):

| ขั้นตอน | การคำนวณ | ค่าที่ได้ |
|---|---|---|
| $t_1$ | $23 \times 3600 + 50 \times 60 + 0$ | $85,800$ วินาที |
| $t_2$ | $0 \times 3600 + 10 \times 60 + 0$ | $600$ วินาที |
| $t_2 - t_1$ | $600 - 85800$ | $-85,200$ วินาที (ติดลบ) |
| $dt = (-85200) \% 86400$ | Python Modulo | $+1,200$ วินาที |
| $dh$ | $1200 // 3600$ | $0$ ชั่วโมง |
| $dt \%= 3600$ | $1200 \% 3600$ | $1200$ |
| $dm$ | $1200 // 60$ | $20$ นาที |
| $ds$ | $1200 \% 60$ | $0$ วินาที |
| **Output** | `f"{dh}:{dm}:{ds}"` | `0:20:0` ✅ ถูกต้องแม่นยำ |

---

### 🎙️ 5. สคริปต์คำพูดสำหรับใช้สอน / Live Code
> **ผู้สอน:** *"หลักการแก้ปัญหาเวลาในสายคอมพิวเตอร์จำกฎนี้ไว้เลยครับ: **'ยุบเป็นหน่วยที่เล็กที่สุดก่อนเสมอ'** (Convert to Base Unit)*
> *อย่าเพิ่งเอาชั่วโมงลบชั่วโมง นาทีลบนาที เพราะเวลาต้องทดเลข (เช่น 00 นาที ลบ 50 นาที) จะเขียน if-else ซับซ้อนมาก*
> *พอยุบเป็นวินาทีแล้ว ทุกอย่างกลายเป็นตัวเลขธรรมดา ลบกันเสร็จค่อยเอามาแจกคืนด้วย `//` กับ `%` ครับ"*

## แบบฝึกหัดเสริม: แปลงอุณหภูมิ

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
รับค่าอุณหภูมิในหน่วยองศาเซลเซียส ($C$) แล้วแปลงเป็นองศาฟาเรนไฮต์ ($F$) และเคลวิน ($K$)
- สูตร: $F = \frac{9}{5}C + 32$
- สูตร: $K = C + 273.15$

---

### 💻 2. โค้ดเฉลยฉบับสมบูรณ์
```python
c = float(input())
f = (9 / 5) * c + 32
k = c + 273.15
print(f"{f} {k}")
```

---

### 🔍 3. อธิบายการทำงาน
- `c = float(input())`: รับค่าตัวเลขอุณหภูมิเป็นทศนิยม (`float`)
- `(9 / 5) * c + 32`: คำนวณฟาเรนไฮต์ โดย `9 / 5` ใน Python 3 จะได้ `1.8` เสมอ
- `print(f"{f} {k}")`: แสดงผลตัวเลขทั้งสองคั่นด้วยช่องว่างตามข้อกำหนด

## แบบฝึกหัดเสริม: Triangle

### 🎯 1. วิเคราะห์โจทย์และเป้าหมาย
คำนวณพื้นที่สามเหลี่ยมจากความยาวด้าน 2 ด้าน ($a, b$) และมุมที่อยู่ระหว่างด้านทั้งสอง ($C$ ในหน่วยองศา)
- สูตร: $\text{area} = \frac{1}{2}ab \sin(C)$
- **Input:** $a, b, C$ บรรทัดละค่า (รองรับทั้งจำนวนเต็ม ทศนิยม และ scientific notation เช่น `1e1`)
- **Output:** `area = <ผลลัพธ์> (sq cm)`

---

### 💻 2. โค้ดเฉลยฉบับสมบูรณ์
```python
import math

a = float(input())
b = float(input())
c = float(input())

# คำนวณพื้นที่สามเหลี่ยม (อย่าลืมแปลงองศาเป็นเรเดียน)
area = 0.5 * a * b * math.sin(math.radians(c))

print(f"area = {area} (sq cm)")
```

---

### 🔍 3. อธิบายการทำงาน
- `float(input())`: ฟังก์ชัน `float()` ของ Python สามารถแปลงสตริงที่อยู่ในรูปแบบ Scientific notation เช่น `'1e1'` ให้กลายเป็น `10.0` หรือ `'2e1'` กลายเป็น `20.0` ได้อัตโนมัติ
- `math.radians(c)`: จำเป็นต้องแปลงมุม $C$ จากองศาเป็นเรเดียนก่อนเข้าฟังก์ชัน `math.sin()`
- `f"area = {area} (sq cm)"`: จัดข้อความผลลัพธ์ให้ตรงตามโจทย์เป๊ะทุกตัวอักษร
